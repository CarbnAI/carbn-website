# Carbn logo pack

Generated by `npm run logo-pack` from the approved mark (Slip) and wordmark.
Do not edit these files by hand: change the source and regenerate.

## What to use where

| You are making         | Use                                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------- |
| A website or app       | `logo/svg/` for the logo, `web/` for favicons, icons, the Open Graph image and `CarbnLogo.tsx` |
| A social profile       | `social/avatar/` for the profile picture, `social/banners/` for the header                     |
| A social post or story | `social/posts/`                                                                                |
| A presentation         | `slides/` for title cards; `logo/png/` (transparent) or `logo/svg/` for logos on slides        |
| Anything printed       | `print/` (vector PDF). Send these to the printer, not PNGs                                     |
| Video or broadcast     | `logo/png/lockup/` at 4096px, reversed or mono-white over footage                              |

Google Slides does not accept SVG: use the PNGs. PowerPoint 365 and Keynote accept SVG and PDF.

## Forms

| Form               | When                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| Horizontal lock-up | The default. Headers, documents, most placements.                                |
| Stacked lock-up    | Square and tall spaces, and anywhere the horizontal would fall under 120px wide. |
| Mark               | Avatars, app icons, favicons, and once the name is already on screen.            |
| Wordmark           | Rare. Only where the mark already appears nearby.                                |

## Colourways

| File suffix    | Background | When                                                     |
| -------------- | ---------- | -------------------------------------------------------- |
| `graphite`     | Light      | Light backgrounds. The default.                          |
| `reversed`     | Dark       | Dark backgrounds, photography, video.                    |
| `volt-on-dark` | Dark       | Dark backgrounds only. The signature version.            |
| `volt`         | Dark       | Dark backgrounds only. Merchandise and signage.          |
| `mono-black`   | Light      | One-colour print, engraving, embossing, legal documents. |
| `mono-white`   | Dark       | Knock-outs, etching, overlays on dark footage.           |
| `current`      | Any        | Web only. Takes the colour of the surrounding text.      |

**There is no Volt logo for light backgrounds, on purpose.** Volt on a light page measures 1.08:1 and disappears. On light, use graphite, or put the graphite logo on a Volt field (the `volt` social and slide files).

## Colour values

| Colour       | HEX       | RGB           | Print                                                              |
| ------------ | --------- | ------------- | ------------------------------------------------------------------ |
| Volt         | `#D0FE00` | 208, 254, 0   | CMYK 18/0/100/0 (approx.) · spot PANTONE 809 C                     |
| Graphite 950 | `#08090B` | 8, 9, 11      | K100 for type and marks · rich black 60/40/40/100 for large fields |
| Graphite 50  | `#F4F5F7` | 244, 245, 247 | Paper white. No ink                                                |

Fluorescent yellow-green. Proof against a physical guide; the nearest solid ink must be matched by eye. Fluorescent colour cannot be reproduced in process CMYK: the CMYK value prints as a flat yellow-green. For the real Volt in print, use the spot-ink PDFs.

## Clear space and minimum size

- Clear space is **x**, the height of the upper piece of the mark: 12 of the logo's 32 units, or 37.5% of the mark's height. Nothing enters it.
- Screen: mark at least **24px**; horizontal lock-up at least **120px** wide, otherwise use the stacked lock-up.
- Print: mark at least **10mm**; horizontal lock-up at least **40mm** wide. Embroidery: mark at least **20mm**. These are starting points; confirm with the vendor, because the gap in the mark is the first thing to fill in.

## Web install

Copy `web/` to your site root and paste `web/head.html` into `<head>`. `favicon.svg` switches from graphite to Volt when the browser is in dark mode. `favicon.ico` is the fallback for older browsers.

```tsx
import { CarbnLogo } from './CarbnLogo';
<CarbnLogo form="lockup" colorway="current" height={32} />
<CarbnLogo form="mark" colorway="volt" height={24} />   // dark backgrounds only
```

| `carbn-mark-volt-spot.pdf`          | one spot ink, PANTONE 809 C                           | 40 mm wide (vector: scales freely)  |
| `carbn-lockup-volt-white-spot.pdf`  | two spot inks for dark stock: PANTONE 809 C and White | 150 mm wide (vector: scales freely) |
| `carbn-stacked-volt-white-spot.pdf` | two spot inks for dark stock: PANTONE 809 C and White | 90 mm wide (vector: scales freely)  |

Spot-ink PDFs carry named separations, so the printer gets one plate per ink. The White plate in `volt-white-spot` files is for printing on dark garments and stock; it previews as white on white. If a vendor asks for EPS or AI, open the PDF in Illustrator and save it in that format.
